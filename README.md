# CAMPUSBITE – College Canteen Ordering System

## 1. Introduction
CampusBite is a simple web-based College Canteen Ordering System developed as an individual Java mini project. It helps students view food items, add items to their cart, calculate the bill, and place food orders conveniently.

## 2. Objectives
- To make food ordering easier for college students.
- To display available food items and their prices.
- To manage selected items through a shopping cart.
- To calculate the total order amount.
- To store customer orders in a MySQL database.

## 3. Technologies Used

**Frontend:**
- HTML
- CSS
- JavaScript

**Backend:**
- Java
- Spring Boot

**Database:**
- MySQL

**Development Tools:**
- Visual Studio Code
- MySQL Workbench
- GitHub

## 4. Main Features
1. Home and Dashboard – Provides navigation to different sections.
2. Menu – Displays available food items and prices.
3. Shopping Cart – Allows users to add, remove, and update food quantities.
4. Bill Calculation – Calculates the order amount.
5. Order Placement – Sends order details to the Java backend.
6. My Orders – Provides an order history section.
7. About Page – Displays project information.

## 5. Project Structure

- Frontend HTML files
- CSS styling
- JavaScript functionality
- Backend Java source files
- Spring Boot configuration
- Maven pom.xml file
- MySQL database

## 6. Database
The project uses a MySQL database named `campusbite`.

The `orders` table stores:
- Order ID
- Customer Name
- Ordered Items
- Total Amount
- Order Status
- Order Creation Time

## 7. How to Run the Project

1. Install Java and MySQL.
2. Open the backend folder in the terminal.
3. Configure the MySQL database connection in `application.properties`.
4. Start the Spring Boot application.
5. Open the frontend using Visual Studio Code Live Server.
6. Browse the menu, add food items to the cart, and place an order.

## 8. Conclusion
CampusBite provides a basic digital solution for college canteen food ordering. This project demonstrates frontend development, Java backend integration, database connectivity, and basic order management.
